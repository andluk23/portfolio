# Andluk Website

Files:
- `index.html` — main page
- `other-servers.html` — other servers page
- `style.css` — website styling
- `assets/` — images/logos

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload all files and the `assets` folder, keeping this exact structure.
3. Open the repository's **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. GitHub will show the public website URL after deployment.

Important: `index.html`, `other-servers.html`, and `style.css` must stay in the repository root.
